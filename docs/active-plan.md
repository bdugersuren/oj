## 2. Алхмуудын дэлгэрэнгүй тайлан (Detailed Milestones & Changes)

### ШАТ 1: DMOJ Холболтын Алдаанууд
* DMOJ Bridge-ийн тохиргоог зөв зам руу зааж, Sandbox ажиллагааг нээсэн.
* `GET /api/v1/admin-settings/judges/health` API-аар холболтыг шалгах боломжтой болгов.

### ШАТ 2: Local Judge (Dockerless Subprocess Sandbox)
* Docker-гүй, локал Celery болон FastAPI сервер дээр шууд ажиллах локал шүүгч хөгжүүлэв.
* C++, C, Java, Python, Pascal хөрвүүлэлтийг хийж, `psutil` ашиглан цаг болон санах ойн хязгаарлалтыг бодит хугацаанд хянаж аюулгүй ажиллуулна.

### ШАТ 3: Багшийн вэб Workspace (Polygon)
* Багш нар олимпиадын бодлогуудыг засах, бэлдэх ажлын талбарыг Monaco Editor ашиглан орчин үеийн загвараар бүтээв.
* Үүнд `statement.md`, `init.yml`, `solution.cpp`, `generator.cpp` файлуудыг удирдах, тест кэйсийг автоматаар бэлдэх боломжийг олгосон.

### ШАТ 4: Testlib & Custom Checker дэмжлэг
* `testlib.h` толгой файлыг `/usr/include/` замд глобалаар суулгаж өгснөөр C++-ээр бичигдсэн checker болон generator хэвийн ажиллах нөхцөл бүрдэв.
* Subtask (багц тестүүд) дэмждэг болгож шинэчлэв. Багц дотор нэг л тест унахад нийт багцын оноо 0 болно.

### ШАТ 5: Багшийн Workspace Сайжруулалт
* **Шинэ Файл & Загварууд**: Monaco Explorer дээр New File, Delete File товчлуурууд нэмж, `checker.cpp` нэмэхэд Testlib загвар кодыг автоматаар бичдэг болов.
* **Зураг & Assets**: Өгүүлбэрт оруулах зургуудыг `assets/` замд хадгалан, нийтлэгдсэн болон драфт үед зөв mime-type-тай үйлчлэх backend API бэлтгэж, frontend `MarkdownRenderer`-т харьцангуй замуудыг API холбоос руу хөрвүүлдэг болгов.
* **Preview Modal**: Markdown өгүүлбэр, зураг болон математик томьёо хэрхэн харагдахыг "Харах (Preview)" товчоор Live Preview Modal-оор харуулна.
* **Параметрүүдийг сэргээх**: Вэб хуудсыг дахин ачаалахад генераторын параметр, оноог draft-аас автоматаар уншиж бөглөнө.
* **Эхний тест кэйсийн sample тохиргоо**: Генератороор үүсгэсэн тестүүдийн хамгийн эхний теслийг `sample: true` болгох тохиргоо нэмж, сурагчийн бодлогын хуудас дээр зөв харуулна.
