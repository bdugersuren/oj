# Мэдээлэлзүйн Бодлогын Бүх Төрлийг Турших ба Баталгаажуулах Заавар

Энэхүү баримт бичиг нь системд шинээр нэвтрүүлсэн **Нэгдсэн Бодлогын Багц (Unified Secure Problem Package)** болон шүүлтүүрийн бүх хэлбэрийг (Interactive, Custom checker, Function signature grading) орон нутгийн орчинд алхам алхмаар хэрхэн шалгаж, тестлэх зааварчилгааг агуулна.

---

## 🔑 Алхам 2: Админ/Багш Эрхээр Бодлого Оруулах (Ingestion)

Шинээр үүсгэсэн `/api/v1/problems/upload-package` endpoint-оор дамжуулан бэлтгэсэн ZIP багцуудыг системд оруулна.

### 1. API Хүсэлт илгээх (Swagger UI эсвэл Postman ашиглах)
- **Method**: `POST`
- **URL**: `http://localhost:8000/api/v1/problems/upload-package?code=<PROBLEM_CODE>`
  - Жишээ кодууд: `TEST_INT` (Interactive), `TEST_CHECK` (Custom Checker), `TEST_SIG` (Function Signature)
- **Headers**:
  - `Authorization: Bearer <your_teacher_jwt_token>`
- **Body (form-data)**:
  - `file`: Татаж авсан сэдэвчилсэн `.zip` багцыг сонгон хавсаргана.

### 2. Арын урсгал:
- Сервер zip файлыг уншиж, `public/` хавтасны өгүүлбэр, pdf, зургуудыг **нээлттэй `oj-public-assets`** bucket рүү хуулна.
- `private/` хавтсыг дахин баглаж `cases.zip` болгон **нууцлагдсан `oj-private-problems`** bucket рүү хуулна.
- `private/init.yml`-ийг уншиж, өгөгдлийн санд бодлогын мета мэдээлэл болон жишээ (sample) кэйсүүдийг бүртгэнэ.

## 📝 Алхам 3: Сурагчийн Эрхээр Код Илгээж Шалгах

Бодлого тус бүрд тохирох зөв болон буруу код илгээн шүүлтүүрийн үр дүнг шалгана.

### 1. Interactive Guessing Game (`TEST_INT`)
Сурагчийн код ба шүүгч системийн `interactor.py` скрипт хоорондоо стандарт оролт гаралтын сувгаар (pipes) харилцан ажиллаж, систем дэх нууц тоог хайж олно.

- **Зөв Хариулт (Binary Search ашигласан С++ шийдэл)**:
  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      int low = 1, high = 100;
      while (low <= high) {
          int mid = (low + high) / 2;
          std::cout << mid << std::endl;
          std::string response;
          if (!(std::cin >> response)) break;
          if (response == "=") {
              break;
          } else if (response == ">") {
              low = mid + 1;
          } else {
              high = mid - 1;
          }
      }
      return 0;
  }
  ```
  *Шүүлтүүрийн дүн: `AC` (Accepted)*

- **Буруу Хариулт (Ганцхан оролдлого хийгээд зогсох)**:
  ```cpp
  #include <iostream>
  int main() {
      std::cout << 50 << std::endl;
      return 0;
  }
  ```
  *Шүүлтүүрийн дүн: `WA` эсвэл `RTE` (оролдлогын тоо хэтэрсэн)*

---

### 2. Custom Checker (`TEST_CHECK`)
Өгөгдсөн тооноос бага эсвэл тэнцүү ямар нэгэн тэгш тоо хэвлэхийг шаардана. Шүүгч систем `checker.py` скриптийг ажиллуулан хариуг шалгана.

- **Зөв Хариулт (Тэгш тоо хэвлэх)**:
  ```cpp
  #include <iostream>
  int main() {
      std::cout << 10 << std::endl; // 10 нь тэгш тоо бөгөөд 15-аас бага тул зөв
      return 0;
  }
  ```
  *Шүүлтүүрийн дүн: `AC` (Accepted)*

- **Буруу Хариулт (Сондгой тоо хэвлэх)**:
  ```cpp
  #include <iostream>
  int main() {
      std::cout << 11 << std::endl; // 11 сондгой тул буруу
      return 0;
  }
  ```
  *Шүүлтүүрийн дүн: `WA` (Wrong Answer)*

---

### 3. Function Signature Grading (`TEST_SIG`)
Сурагч өөрийн кодод `main` функц бичих шаардлагагүй, зөвхөн өгөгдсөн `add` функцийг хэрэгжүүлж илгээнэ. Шүүгч нь сурагчийн кодыг өөрийн `grader.cpp` wrapper-тай холбон compile хийнэ.

- **Зөв Хариулт**:
  ```cpp
  #include "grader.h"

  int add(int a, int b) {
      return a + b;
  }
  ```
  *Шүүлтүүрийн дүн: `AC` (Accepted)*

- **Буруу Хариулт (Логик алдаатай функц)**:
  ```cpp
  #include "grader.h"

  int add(int a, int b) {
      return a - b; // Нийлбэрийн оронд зөрүү гаргах
  }
  ```
  *Шүүлтүүрийн дүн: `WA` (Wrong Answer)*

## 🔒 Алхам 4: Аюулгүй байдлын хамгаалалтыг шалгах (Security Verification)

Олимпиад тэмцээний үеэр тест кэйсүүд задрахгүй байгааг дараах байдлаар шалгаж баталгаажуулна:

1. **Нээлттэй файлуудын холбоосыг шалгах (Зөвшөөрөгдөх ёстой)**:
   Хөтөч дээрээс `http://localhost:9000/oj-problems/TEST_INT/statement.md` хаяг руу хандахад файл амжилттай харагдах ёстой.
2. **Хаалттай тест кэйсүүдийн холбоосыг шалгах (Хориглох ёстой)**:
   Хөтөч дээрээс `http://localhost:9000/oj-private-problems/TEST_INT/cases.zip` хаяг руу шууд хандахад MinIO систем `AccessDenied (403)` алдаа буцааж, гадагш татахыг хориглоно.
